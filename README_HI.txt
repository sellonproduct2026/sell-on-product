SELL ON PRODUCT वेबसाइट - शुरुआत कैसे करें

1. ZIP फाइल को Extract करें।
2. index.html पर क्लिक करके वेबसाइट अपने मोबाइल/कंप्यूटर के ब्राउज़र में देखें।
3. WhatsApp ऑर्डर चालू करने के लिए script.js खोलें।
4. सबसे ऊपर WHATSAPP_NUMBER में 91 के बाद अपना 10 अंकों का नंबर लिखें।
   उदाहरण: const WHATSAPP_NUMBER = "919876543210";
5. script.js में products सूची के अंदर नाम, कीमत और मॉडल बदलकर अपने असली प्रोडक्ट जोड़ें।
6. अभी प्रोडक्ट की तस्वीरों की जगह डिजाइन वाले नमूना चित्र हैं। असली बिक्री से पहले हर प्रोडक्ट की वास्तविक फोटो, सही मोबाइल मॉडल, कीमत, डिलीवरी/रिटर्न नीति और संपर्क जानकारी डालें।

फ्री में ऑनलाइन प्रकाशित करना:
- GitHub पर अकाउंट बनाएं।
- नई Public repository बनाएं, उदाहरण: sell-on-product
- इस ZIP की सभी फाइलें repository में Upload करें।
- Repository Settings > Pages में जाएँ।
- Deploy from a branch चुनें, Branch: main और folder: / (root) चुनकर Save करें।
- GitHub कुछ समय बाद आपकी वेबसाइट का फ्री लिंक देगा।

ध्यान दें:
यह शुरुआती स्टोरफ्रंट है। इसमें अभी ऑनलाइन पेमेंट, ग्राहक लॉगिन, ऑर्डर डेटाबेस या एडमिन पैनल नहीं है। WhatsApp Checkout के जरिए ग्राहक ऑर्डर भेजेंगे। वास्तविक ग्राहकों से ऑर्डर लेने से पहले सभी नमूना जानकारी बदलें।
